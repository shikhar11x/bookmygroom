# BookMyGroom

**BookMyGroom** is a salon appointment booking application built with Flutter, designed to simplify salon discovery, service selection, stylist booking, and online payments through a seamless user experience.

## Features

- Salon service discovery and selection
- Appointment booking and management
- Stylist selection
- Secure authentication
- Online payment integration
- Rewards and promotional offers
- Modern and user-friendly interface

## Tech Stack

- **Frontend:** Flutter, Dart
- **State Management:** Riverpod
- **Navigation:** GoRouter
- **Backend:** Supabase
- **Payments:** Razorpay

## Getting Started

Clone the repository and install the dependencies:

```bash
git clone https://github.com/shikhar11x/bookmygroom
cd bookmygroom
flutter pub get
flutter run
```

## Security

Store sensitive credentials and API secrets securely using environment variables or Supabase secrets. Never commit private keys or credentials to version control.
